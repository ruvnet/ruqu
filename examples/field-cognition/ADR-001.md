# ADR 001: Evaluate bounded field recurrence against classical temporal inference

Status: experimental, rejected for promotion after iteration 1.

## Decision and rationale

Use the actual pinned RuQu npm WASM simulator for a one qubit contextual readout, with a closed form classical equivalent as a control. Keep the bounded field implementation a plainly labelled local reference implementation; it is not the upstream RuField crate. Ordinary Bayesian filtering is the strongest comparator on this synthetic workload and is the next design baseline.

Input is a timestamped asynchronous stream from four synthetic sensors. All predictors receive the same event information. Output is probability of the shared binary latent state, plus replay evidence. One writer owns the workspace. No production sensor, physical actuator, inference API or quantum hardware is connected.

Field update: d=1-exp(-0.12*dt); x_i'=exp(-0.02*dt)*[(1-d)*x_i+d*(x_left+x_right)/2]. An observed sensor then blends 0.5 of its state with 0.5 of the observation clipped to [-4,4]. Reset clears all states. Strictly increasing timestamps and finite observations are required. Missing values permit decay and diffusion. Convex mixing preserves the bound. No learned parameters.

The quantum control applies RY(theta), RZ(phi), RY(beta) to |0>. Its exact classical probability is [1-cos(theta)cos(beta)+sin(theta)cos(phi)sin(beta)]/2. This is classical quantum simulation, with an exact inexpensive classical equivalent for the tested circuit. A phase by itself cannot change this computational basis probability; the final rotation creates sensitivity to phase.

## Evidence and decision

Frozen protocol SHA256: c735f8e6fb79eaa7ff9ff817772815a794e70bfc945fcb6f869654b51d7a3565.
Five fresh preregistered seeds, now disclosed; 10,000 events, no tuning, all events scored. Bayesian error 7.83%, EMA 8.77%, field 12.26%, field without diffusion 12.38%, RuQu readout 16.10%, phase zero 16.97%, exact analytic readout 16.10%. Field relative error reduction averaged by seed is -58.94%, with an approximate five-seed 95% t interval [-81.13%, -36.74%]. These are seed-level uncertainty estimates on one synthetic generator, not evidence about real deployments.

Transition error (first five events after actual flips): Bayesian 38.16%, field 64.08%. The previous bootstrap excluded transitions. This run demonstrates why the stronger evaluation matters. No candidate meets the 10% improvement requirement. Keep all negative results and preserve the baseline.

The 205 circuit test has max absolute error 4.44e-16 against the analytic expression. Seven correctness checks passed in ruOS Node 20 and local Node 24. All raw events and predictions reproduce byte for byte across the two runtimes. Timings are diagnostic: fixed model order, no warmup, shared field computation excluded from RuQu and analytic readout latency. No speedup claim is supported. ruOS peak process RSS is 80,332 KiB including all models and raw result storage. Additional provider spend: $0; existing compute cost unknown.

## Next experiment

Keep iteration 1 immutable. Build a new candidate that decays stale sensor contributions and accounts for change points, then preregister fresh test seeds after development. Test model mismatch, irregular hazard, heterogeneous sensor noise and out of order delivery with an explicit reorder policy. Do not tune to these disclosed test seeds. Reuse the existing pinned native RuField integration in ruqu/integrations/observer-world once an authorized Rust executor is available; do not replace it with a stub. Independently review any changes to the evaluator.
